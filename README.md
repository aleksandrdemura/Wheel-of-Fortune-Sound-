#🎡 Wheel of Fortune (Sound) — крути колесо, выигрывай призы, слушай музыку

> «Крути, пока не выиграешь!»

**Wheel of Fortune (Sound)** — это набор консольных утилит для симуляции вращения колеса фортуны с призами.  
Программа выбирает случайный приз, демонстрирует анимацию вращения в консоли и воспроизводит звуковые сигналы при каждом секторе.

## 🚀 Особенности
- 🎡 Анимация вращения в консоли (прогресс-бары или ASCII-спиннеры).
- 🎁 Список призов настраивается (по умолчанию: 8 секторов).
- 🔊 Воспроизведение звука для каждого сектора (beep с разной частотой или мелодия).
- 🎨 Цветной вывод в терминале.
- ⌨️ Интерактивный режим: нажмите Enter, чтобы запустить вращение.
- 📋 Вывод результата с поздравлением.
- ⚙️ Настройка количества секторов и призов через аргументы (где реализовано).

## 🛠️ Установка и запуск

Для звука используется `beep` (Linux) или `winsound` (Windows).  
**Установка beep (Linux):** `sudo apt install beep`

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `colorama` (опционально)             | `python wheel.py`                       |
| Go         | стандартная библиотека               | `go run wheel.go`                       |
| JavaScript | Node.js, `readline`                  | `node wheel.js`                         |
| Java       | стандартная библиотека               | `javac Wheel.java && java Wheel`        |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `colored` (crates)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby wheel.rb`                         |
| PHP        | стандартная библиотека               | `php wheel.php`                         |
